# 鸣潮资源下载

在仓库根目录运行 `node Scripts/WW-Downloader/down.js`。Node.js 需 20 或更新版本。

下载配置在 `down.js` 顶部：

- `versionType`：`default` 为正式版，`pre` 为预下载；预下载未开放时会报错。
- `resourceLevel`：`UHD` 极致、`HD` 高清、`SD` 流畅；自动包含公共资源。
- `targetDir`：保存目录。同目录切换版本或画质会先校验已有文件。
- `-c 8`、`--concurrency=8` 或环境变量 `DOWNLOAD_CONCURRENCY=8`：所有文件合计的下载连接上限，默认 16，限制为 4–16。最多同时处理 4 个文件，优先大文件，按剩余大小和可用连接重新分配；小文件、尾部数据或不支持 Range 的服务器可能用不满额度。

## aria2 引擎

脚本依次使用 `ARIA2C_PATH` 指定的可执行文件、PATH 中的 `aria2c`、本目录的固定版本缓存。

Windows x64 缺失本机引擎时，会自动从 aria2 官方 GitHub Release 获取 **1.37.0** 到 `.aria2/1.37.0/`。下载有超时和大小限制，并分别校验 ZIP 与解压后可执行文件的 SHA-256。缓存和下载资源均被 `.gitignore` 忽略。无效的显式路径或校验失败会报错，不会执行未验证的缓存。其他系统请自行安装 aria2，或设置 `ARIA2C_PATH`。

aria2 在本机随机端口运行带随机凭据的 RPC；脚本退出前会关闭自己启动的引擎。不会连接或关闭其他 aria2 实例。

## 下载与续传

正常下载由 aria2 **直接写一个 `<文件名>.download` 数据文件**，另有很小的 `.download.aria2` 断点控制和 `.download.json` 资源身份记录。没有碎片目录，也没有完成后的整文件合并。MD5 校验通过后，同目录改名为目标文件；下载与校验继续显示进度。

按 Ctrl+C 会停止补充任务、保存断点并输出中断统计，再次运行只补缺失数据。不要删除或单独搬走 `.download` 及其控制文件；数据文件可能是稀疏文件，文件长度不能代表已下载量。若控制丢失，脚本会校验是否已完整；无法确认完整时安全重下。

旧版 `.parts` 碎片或不完整目标文件会一次性导入单个原生数据文件，导入有进度。这一步需要本地复制和相应磁盘空间，之后不再合并。原始数据保留到完整 MD5 校验通过才清理；导入中断可重做。旧来源校验失败时，重试会从服务器下载，避免反复使用同一批损坏数据。

本次传输统计按 aria2 回报的有效写入增量计算，包括重试、不包括本地导入及校验读取；HTTP/TLS 头和被丢弃的传输数据不计入。恢复的已有数据单独计入总进度。

## 验证

仓库根目录执行 `pnpm test`。下载器集成测试会启动本地 HTTP 服务器和真实 aria2，所有数据使用临时目录，不访问游戏资源目录；aria2 获取规则与正常运行相同。可预先设置 `ARIA2C_PATH` 使用本机引擎。
